# Cameron Grindle — Five Beats preview

**Staging copy only.** This public GitHub Pages repository contains a visual development preview for the approved `Different worlds. Same instinct.` homepage and its `Notice / Ask / Follow / Dare / Discover` chapters.

## Source of truth
Main website: https://github.com/Copper-Button-Games/cameron-grindle-website
Development branch: `five-beats-redesign`
Draft PR: https://github.com/Copper-Button-Games/cameron-grindle-website/pull/1

## Publishing this preview
In this repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**; select **main** and **/(root)**, then **Save**.

Expected preview: https://copper-button-games.github.io/cameron-grindle-preview/

Do not configure a custom domain or add a `CNAME` file. The live site at https://camerongrindle.com is separate.

## Known draft limitations
- Paired hero/beat illustrations, character portraits and series backgrounds are clearly labeled placeholders pending approved story artwork.
- Character discussion content is editorial placeholder, not quotations from the books.
- Newsletter is not collecting signups; the service/privacy integration is pending.
- This preview is public, not password protected.
- Live site links/series pages in the original repo are unchanged.

## Local preview
Download the code and open `index.html` in a browser. No build tools are required.
